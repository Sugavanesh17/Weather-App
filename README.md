# Weather App  

A simple Weather App built using **HTML, CSS, and JavaScript** that fetches real-time weather data from the OpenWeatherMap API. Users can view the current weather conditions, including temperature, humidity, and weather descriptions for any city.

## Features  
- Search for current weather by city.  
- Displays temperature, humidity, and weather description.  
- Fully responsive design for various screen sizes.

## Technologies Used  
- **HTML**: Provides the structure of the application.  
- **CSS**: Adds styling and layout to enhance the look.  
- **JavaScript**: Handles dynamic interactions and API requests.  
- **OpenWeatherMap API**: Fetches live weather data.
